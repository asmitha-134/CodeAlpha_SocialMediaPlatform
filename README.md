# ConnectHub – Social Media Platform

ConnectHub is a Django-based social media platform developed as part of the CodeAlpha Full Stack Development Internship.

## 🚀 Features

* User Registration and Login
* Create Posts
* Upload Post Images
* Edit and Delete Posts
* Like and Unlike Posts
* Add Comments
* Follow and Unfollow Users
* User Profile
* Edit Profile and Profile Picture
* Search Users
* Responsive and Attractive UI
* Django Admin Panel

## 🛠️ Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite
* Pillow
* Git & GitHub

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/asmitha-134/CodeAlpha_SocialMediaPlatform.git
```

### 2. Open the project folder

```bash
cd CodeAlpha_SocialMediaPlatform
```

### 3. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install django pillow
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Run the development server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
